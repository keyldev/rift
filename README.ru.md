## Возможности

- Сколько угодно панелей рядом и друг под другом, у каждой свои вкладки и история
- Вкладки перетаскиваются между панелями и к краю панели, чтобы её разделить; закреплённые вкладки; возврат закрытых
- Сессия (раскладка, вкладки, виды, окно) возвращается после перезапуска; раскладки можно сохранять как рабочие пространства
- Копирование и перемещение между панелями: F5 / F6, перетаскиванием или Ctrl+C / Ctrl+V
- Перетаскивание в Проводник и из него, буфер обмена совместим с Проводником (включая «Вырезать»)
- Панель операций с прогрессом, паузой и отменой; диалог конфликтов с «для всех»
- Отмена (Ctrl+Z) копирования, перемещения, переименования, новой папки и удаления в корзину
- Удаление в корзину или насовсем; корзину можно открыть, восстановить из неё файлы или очистить
- Контекстное меню с действиями Rift и полным меню Проводника (7-Zip, Git, «Отправить»…) в «Других параметрах»
- Системные иконки файлов, окна «Свойства» и «Открыть с помощью»
- Папки обновляются сами, когда файлы меняются на диске
- Скрытые и системные файлы по запросу (Ctrl+H)
- Переименование прямо в списке, новая папка
- Сортировка по любой колонке, ширина и выбор колонок; виды «таблица», «плитки», «эскизы»
- Область просмотра: картинки, текст и код, эскизы видео и PDF
- Фильтр набором текста, рекурсивный поиск с результатами в отдельной вкладке
- Палитра команд (Ctrl+K): команды, недавние папки, вкладки, пути
- Редактируемая адресная строка с автодополнением, «крошки» пути, назад / вперёд / вверх
- Сайдбар: закреплённые папки, быстрый доступ, «Этот компьютер», библиотеки, сеть, корзина, диски
- Тёмная и светлая темы, свой титлбар
- Одно окно: «Открыть в Rift» и список переходов на панели задач (недавние папки) открывают вкладки в уже запущенном Rift
- «Открыть в Rift» в контекстном меню Проводника
- Настройки (Ctrl+,): тема (тёмная, светлая, как в Windows), акцентный цвет, Mica в Windows 11, язык, сочетания клавиш
- Теги на файлах и папках: точки в списке и раздел в сайдбаре
- Интерфейс на русском и английском

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| Tab / Shift+Tab | Следующая / предыдущая панель |
| Ctrl+Tab / Ctrl+Shift+Tab | Следующая / предыдущая вкладка |
| Ctrl+\\ / Ctrl+Shift+\\ | Разделить вправо / вниз |
| Ctrl+Shift+Enter | Только эта панель / все панели |
| Ctrl+Shift+W | Закрыть панель |
| Ctrl+Shift+T | Вернуть закрытую вкладку |
| F5 / F6 | Копировать / переместить выделенное в другую панель |
| Ctrl+C / Ctrl+X / Ctrl+V | Копировать / вырезать / вставить файлы (работает с Проводником) |
| Del / Shift+Del | В корзину / удалить насовсем |
| F2 | Переименовать |
| Ctrl+Shift+N | Новая папка |
| Ctrl+Z | Отменить (в том числе вернуть файлы из корзины) |
| Shift+F10, клавиша меню | Контекстное меню; Shift+правый клик — сразу меню Проводника |
| Alt+Enter | Свойства |
| Ctrl+Shift+C | Копировать путь |
| Ctrl+H | Показать / скрыть скрытые файлы |
| Ctrl+K, Ctrl+Shift+P | Палитра команд |
| Ctrl+, | Настройки (там же меняются все сочетания клавиш) |
| Ctrl+F, Ctrl+E | Поиск в папке и вложенных |
| Ctrl+L, Alt+D, F4 | Изменить путь |
| Alt+P | Область просмотра |
| Ctrl+Shift+1 / 2 / 3, Ctrl+колесо | Таблица / плитки / эскизы |
| Набор текста в списке | Фильтр; Esc сбрасывает |
| Ctrl+T / Ctrl+W | Новая вкладка / закрыть вкладку |
| Enter, двойной клик | Открыть |
| Backspace, Alt+↑ | Вверх |
| Alt+← / Alt+→ | Назад / вперёд |
| Ctrl+R | Обновить |

Перетаскивание: на тот же диск — перемещение, на другой — копирование; Ctrl — копировать, Shift — переместить. Брось на строку папки, чтобы положить файлы внутрь неё.

## Командная строка

```bash
Rift.exe C:\Projects --right D:\Backup
```

- Без путей Rift возвращает прошлую сессию. С путями открывает ровно их, каждый вкладкой:
  пути без флага и с `--left` — в первой панели, с `--right` — во второй.
- Если Rift уже запущен, пути откроются новыми вкладками в его окне; `--new-window` запускает отдельное окно.
- `shell:MyComputerFolder`, `shell:RecycleBinFolder`, `shell:Libraries` и `shell:NetworkPlacesFolder` открывают
  «Этот компьютер», корзину, библиотеки и сеть.
- `--lang en` или `--lang ru` выбирает язык интерфейса (по умолчанию — как в Windows).
- `--register-shell` / `--unregister-shell` добавляют или убирают «Открыть в Rift» в Проводнике.

## «Открыть в Rift» в Проводнике

Включается в настройках (Ctrl+,) или командой:

```bash
Rift.exe --register-shell
```

Пункт появляется в меню папок, пустого места внутри папки и дисков. Пишется в `HKCU`, права администратора не нужны.
В Windows 11 он находится в «Показать дополнительные параметры». В меню попадает путь к тому `Rift.exe`, из которого включали, так что после переноса exe включи заново.
