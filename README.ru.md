## Возможности

- Две панели рядом, у каждой свои вкладки и история
- Копирование и перемещение между панелями: F5 / F6, перетаскиванием или Ctrl+C / Ctrl+V
- Перетаскивание в Проводник и из него, буфер обмена совместим с Проводником (включая «Вырезать»)
- Панель операций с прогрессом, паузой и отменой; диалог конфликтов с «для всех»
- Отмена (Ctrl+Z) копирования, перемещения, переименования и новой папки
- Удаление в корзину или насовсем
- Переименование прямо в списке, новая папка
- «Крошки» пути, назад / вперёд / вверх, быстрый доступ и диски в сайдбаре
- Тёмная и светлая темы, свой титлбар
- «Открыть в Rift» в контекстном меню Проводника
- Интерфейс на русском и английском

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| Tab | Другая панель |
| F5 / F6 | Копировать / переместить выделенное в другую панель |
| Ctrl+C / Ctrl+X / Ctrl+V | Копировать / вырезать / вставить файлы (работает с Проводником) |
| Del / Shift+Del | В корзину / удалить насовсем |
| F2 | Переименовать |
| Ctrl+Shift+N | Новая папка |
| Ctrl+Z | Отменить |
| Ctrl+T / Ctrl+W | Новая вкладка / закрыть вкладку |
| Enter, двойной клик | Открыть |
| Backspace, Alt+↑ | Вверх |
| Alt+← / Alt+→ | Назад / вперёд |
| Ctrl+R | Обновить |

Перетаскивание: на тот же диск — перемещение, на другой — копирование; Ctrl — копировать, Shift — переместить. Брось на строку папки, чтобы положить файлы внутрь неё.

## Командная строка

```bash
Rift.exe C:\Projects --right D:\Backup
```

- Каждый путь открывается вкладкой; пути без флага и с `--left` — в левой панели, с `--right` — в правой.
- `--lang en` или `--lang ru` выбирает язык интерфейса (по умолчанию — как в Windows).
- `--register-shell` / `--unregister-shell` добавляют или убирают «Открыть в Rift» в Проводнике.

## «Открыть в Rift» в Проводнике

Включается галочкой внизу сайдбара или командой:

```bash
Rift.exe --register-shell
```

Пункт появляется в меню папок, пустого места внутри папки и дисков. Пишется в `HKCU`, права администратора не нужны.
В Windows 11 он находится в «Показать дополнительные параметры». В меню попадает путь к тому `Rift.exe`, из которого включали, так что после переноса exe включи заново.
